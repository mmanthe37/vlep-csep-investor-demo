# Roadmap

## Now - Investor MVP

- Deterministic synthetic six-stage pipeline
- Append-only hash-chain verification
- Six-dimensional CSEP
- ILAE 2017 → 2025 conditional reinterpretation
- Interactive investor workbench
- CI, GitHub Pages, architecture, validation, model/data cards

Exit criterion: a reviewer can reproduce the bundle, run the UI, inspect every transformation, and distinguish implemented behavior from research claims.

## Next - Research Beta

- Versioned mapping registry and reviewer workflow
- Property-based invariant suite
- Synthetic trajectory and stress-test harness
- Executable probabilistic model decision record
- De-identified integration sandbox
- Threat model and independent security review

Exit criterion: pre-registered simulations demonstrate software/model recovery characteristics under declared assumptions; mappings are governed and auditable.

## Later - Clinical Research

- Institutional clinical and data partners
- Gold-standard adjudicated retrospective cohort
- Subgroup, fairness, calibration, and failure-mode analysis
- Prospective protocol and human-factors evaluation
- Regulatory and quality-management strategy

Exit criterion: evidence supports a narrowly defined intended use. No clinical deployment occurs before that evidence and governance exist.
